# 코스 순서 (v3.9, 2026-11-07)

v3.8에서 OpenStreetMap 실제 도보 경로(`backend/app/seeds/data/walk_routes.json`, 300쌍)를 받은 뒤 코스 순서를 다시 봤다. 걷는 속도는 그대로 4 km/h, 걸리는 시간 = (머무는 시간 + 걷는 시간)을 10분 단위로 올림.

## 코스 5 순서 · 재시드 스위치

### 바꾼 것: 코스 5 '정릉과 성곽길'
| | 순서 | 실제 도보 | 걸리는 시간 |
|---|---|---|---|
| 예전 | 정릉(105) → 성북선잠박물관(106) → 한양도성 북악구간(107) | 3,910 m | 210분 |
| **지금** | **정릉(105) → 한양도성 북악구간(107) → 성북선잠박물관(106)** | **3,558 m** (구간 2,500 m · 1,060 m) | 210분 (머무는 150 + 걷는 54 → 210) |

- 출발(정릉 매표소)은 그대로, 끝은 선잠박물관이라 한성대입구역에서 가깝다. 머무는 시간은 장소마다 그대로(105: 50분, 107: 60분, 106: 40분).
- 바꾼 곳: `backend/app/seeds/data/tour_places.json`(코스 5의 106·107 `seq` 맞바꿈), `tours.json` 코스 5 설명("정릉에서 한양도성 북악구간을 걸어 선잠박물관까지, …"), 프론트 목업 `frontend/src/lib/mock/data.ts`.
- 코스 3 '문인의 성북동 산책'은 그대로(111 → 102 → 103 → 104).
- 테스트: `tests/test_walk_routes.py::test_seed_course_times_match_real_routes` — 모든 코스 시간이 walk_routes.json으로 계산한 값과 같은지, 코스 5 순서·거리(3,558 m < 예전 3,910 m)를 본다.

### 배포 DB에 반영 (재시드 스위치)
배포 DB는 비어 있을 때만 시드를 넣는다. `backend/scripts/start.sh`에 `RESEED_ON_START=true`면 `python -m app.seeds`(모두 지우고 다시 넣기)를 돌리는 스위치를 넣었다.
Railway 변수 `RESEED_ON_START=true` → 재배포 → 확인 후 변수 삭제(안 지우면 재시작마다 데모 데이터 초기화). 자세히는 [deploy.md](../deploy.md).
