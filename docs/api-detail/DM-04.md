# 객실 등록

- 번호: DM-04
- Method / Path: `POST /admin/dorms`
- 역할: univ_admin, operator
- 화면: A2
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` (univ_admin 또는 operator) |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "university_id": 1, "building": "프런티어관", "room_type": "double", "price_per_night": 35000, "total_rooms": 20, "open_from": "2027-01-05", "open_to": "2027-02-20", "rules": ["체크인 15:00 / 체크아웃 11:00", "취사 금지"], "photos": ["..."], "active": true }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| university_id | integer | 필수 | 대학 ID. univ_admin은 본인 `university_id`만 가능 |
| building | string | 필수 | 건물명 |
| room_type | string | 필수 | 객실 유형 (예: `single`, `double`) |
| price_per_night | integer | 필수 | 1박 가격 (원) |
| total_rooms | integer | 필수 | 총 객실 수 |
| open_from | date | 필수 | 개방 시작일 |
| open_to | date | 필수 | 개방 종료일 |
| rules | string[] | 선택 | 이용 규칙 |
| photos | string[] | 선택 | 사진 URL |
| active | boolean | 선택 | 활성 여부 (기본 true) |

## Response

201 Created
```json
{ "id": 10, "university_id": 1, "building": "프런티어관", "room_type": "double", "price_per_night": 35000, "total_rooms": 20, "open_from": "2027-01-05", "open_to": "2027-02-20", "rules": ["체크인 15:00 / 체크아웃 11:00", "취사 금지"], "photos": ["..."], "active": true }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음, 만료 또는 유효하지 않음
- 403 FORBIDDEN: 허용되지 않은 역할이거나 univ_admin이 타 대학에 등록 시도
- 404 NOT_FOUND: `university_id`에 해당하는 대학 없음
- 422 VALIDATION: 필수값 누락, 가격·객실 수 음수, `open_to < open_from`

## 비고

- 권한: univ_admin은 자기 `university_id` 소속 객실만 등록, operator는 전체.
- 등록된 값이 이후 조회·예약의 사실 기준(DB 값)이 됨.
