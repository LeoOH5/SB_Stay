# 내 등급·정산율 — v3.2, v3.7 매달 평가

- 번호: BD-08
- Method / Path: `GET /buddy/grade` (휴면 복귀: `POST /buddy/confirm-active`, 응답 같음)
- 역할: buddy
- 화면: B05 내 활동 (등급 카드)
- 우선순위: 권장
- 처리: 구현

## 규칙
- 매달 1일, **지난달 완료 동행**(그 달만, 누적 아님)과 **누적 후기·평점**으로 다시 정한다.
- 성장 75%: 지난달 동행 ≥ 4 · 후기 ≥ 3 · 평점 ≥ 4.3. 우수 80%: 지금 성장(또는 우수) + 지난달 ≥ 7 · 후기 ≥ 5 · 평점 ≥ 4.5. 그 밖에 기본 70%.
- 승인 후 첫 달은 기본. 올라갈 때 한 단계씩, 내려갈 때 바로. 휴면이어도 평가한다.
- 정산율은 예약 확정 때 항목에 고정된다(이 응답의 `payout_rate`는 지금 등급 값).

## Response

200 OK (지우, DEMO_TODAY 2027-01-14)
```json
{
  "grade": "growth", "payout_rate": 0.75,
  "evaluated_for": "2026-12", "next_eval_on": "2027-02-01",
  "stats": { "month": "2026-12", "last_month_walks": 4, "this_month_walks": 3, "reviews": 4, "rating": 4.5 },
  "next": { "grade": "top", "payout_rate": 0.8, "need": { "walks": 7, "reviews": 5, "rating": 4.5 } },
  "keep": { "walks": 4, "reviews": 3, "rating": 4.3 },
  "first_month": false,
  "note": "등급은 매달 1일, 지난달 동행으로 다시 정해요. 올라갈 때는 한 단계씩, 내려갈 때는 조건에 맞는 등급으로 바로 가요.",
  "needs_recheck": false, "dormant_since": null, "updated_at": "2027-01-01"
}
```
- `evaluated_for`: 지금 등급을 정한 평가 달. `updated_at`: 그 평가일(1일).
- `stats.month`·`last_month_walks`: 오늘 기준 지난달과 그 달 완료 동행. `this_month_walks`: 이번 달 지금까지 완료 동행(다음 1일 평가에 쓰임). `reviews`·`rating`: 오늘까지 누적.
- `next`: 한 단계 위 등급과 기준(우수면 null). `keep`: 지금 등급을 지키는 기준(기본이면 null).
- `first_month`: 다음 평가 때도 승인 후 첫 달이라 기본으로 남음.
- v3.6까지 있던 `window`(평가 기간 = 현재 + 직전 방학)는 없어졌다.

`POST /buddy/confirm-active`: 휴면(`needs_recheck`)과 `dormant_since`를 지우고 위 응답을 돌려준다. 등급은 바꾸지 않는다.

## Errors

- 401 UNAUTHORIZED · 403 FORBIDDEN(buddy 아님) · 404 NOT_FOUND(버디 프로필 없음)
