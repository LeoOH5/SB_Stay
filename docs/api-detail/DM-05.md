# 객실 수정

- 번호: DM-05
- Method / Path: `PATCH /admin/dorms/{id}`
- 역할: univ_admin, operator
- 화면: A2
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` (univ_admin 또는 operator) |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 객실 ID (`dorm_rooms.id`) |

Query params: 없음

Body (보낸 필드만 수정)
```json
{ "price_per_night": 38000, "total_rooms": 18, "open_from": "2027-01-05", "open_to": "2027-02-20", "active": true }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| price_per_night | integer | 선택 | 1박 가격 (원) |
| total_rooms | integer | 선택 | 총 객실 수 |
| open_from | date | 선택 | 개방 시작일 |
| open_to | date | 선택 | 개방 종료일 |
| active | boolean | 선택 | 활성 여부 |

## Response

200 OK
```json
{ "id": 10, "university_id": 1, "building": "국제관", "room_type": "double", "price_per_night": 38000, "total_rooms": 18, "open_from": "2027-01-05", "open_to": "2027-02-20", "rules": ["체크인 15:00 / 체크아웃 11:00", "취사 금지"], "photos": ["..."], "active": true }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음, 만료 또는 유효하지 않음
- 403 FORBIDDEN: 허용되지 않은 역할이거나 univ_admin이 타 대학 객실 수정 시도
- 404 NOT_FOUND: 객실 없음
- 422 VALIDATION: 값 형식 오류, 가격·객실 수 음수, `open_to < open_from`

## 비고

- 권한: univ_admin은 자기 `university_id` 소속 객실만 수정, operator는 전체.
- 이미 승인·확정된 예약은 변경되지 않음. `active=false`면 목록·상세 조회에서 제외.
