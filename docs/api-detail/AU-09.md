# 내 이용 방식 (무료 / 버디) — v3.4

- 번호: AU-09
- Method / Path: `GET /auth/me/plan`
- 역할: 전체 (로그인)
- 화면: T08 코스 상세 (오늘 남은 질문 N/3, 광고·한도·설문 표시 여부)
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |

## Response

200 OK
```json
{ "plan": "free", "ai_question_limit": 3, "ai_questions_left_today": 2, "ai_questions_used_today": 1 }
```
버디 이용자: `{ "plan": "buddy", "ai_question_limit": null, "ai_questions_left_today": null, "ai_questions_used_today": 0 }`

## 규칙

- `buddy` = 결제했고(`paid_at` 있음) 취소되지 않은 예약에 살아 있는 버디 항목(requested·approved·confirmed)이 하나라도 있음. 숙박 + 버디, 버디만 모두 해당. 지난 여행도 그대로 `buddy`.
- 그 밖의 관광객은 `free`. 관광객이 아닌 역할(버디·대학 담당자·운영자)은 제한이 없어 `buddy`로 응답.
- 남은 질문은 오늘(`DEMO_TODAY` 기준) `ai_usage` 기록으로 계산. 질문 규칙은 [AI-02](AI-02.md).

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
