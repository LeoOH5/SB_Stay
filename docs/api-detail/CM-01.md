# 약관·환불 규정·고객센터 조회

- 번호: CM-01
- Method / Path: `GET /contents/{key}`
- 역할: 전체
- 화면: 마이페이지, T1
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 콘텐츠 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| key | string | 필수 | `terms` \| `refund` \| `support` \| `intro` |

Query params: 없음

Body: 없음

## Response

200 OK
```json
{ "key": "support", "language": "en", "title": "Customer Support", "body": "Emergency contact: 112 / Seongbuk Stay help desk: +82-2-0000-0000", "updated_at": "2026-11-05T00:00:00Z" }
```

## Errors

- 404 NOT_FOUND: 정의되지 않은 `key`

## 비고

- 해커톤에서는 고정 응답 반환. 언어는 `Accept-Language` 기준이며 없으면 `ko`.
- `support`는 긴급연락처, `intro`는 성북 소개. 콘텐츠 수정 API(AD-09)는 제외.
