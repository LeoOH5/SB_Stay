# 어드민 대시보드

- 번호: AD-01
- Method / Path: `GET /admin/dashboard`
- 역할: univ_admin, operator
- 화면: A1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| from | date | 선택 | 집계 시작일 (YYYY-MM-DD) |
| to | date | 선택 | 집계 종료일 (YYYY-MM-DD) |

Body: 없음

## Response

200 OK
```json
{ "period": { "from": "2027-01-05", "to": "2027-02-20" }, "bookings": 24, "pending": 3, "nights": 72, "dorm_revenue": 2520000, "platform_fee": 252000, "fee_rate": 0.1, "by_status": { "requested": 3, "approved": 8, "confirmed": 11, "cancelled": 2 }, "daily": [ { "date": "2027-01-12", "bookings": 2, "revenue": 140000 } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: univ_admin/operator 외 역할
- 422 VALIDATION: 날짜 형식 오류 또는 `to < from`

## 비고

- univ_admin은 같은 `university_id` 데이터만 집계, operator는 전체.
- 매출·수수료 등 숫자는 DB 집계값.
