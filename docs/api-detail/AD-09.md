# 콘텐츠 관리 (다국어)

- 번호: AD-09
- Method / Path: `PUT /admin/contents/{key}`
- 역할: operator
- 화면: 콘텐츠 관리
- 우선순위: 권장
- 처리: 제외

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |
| Content-Type | 필수 | `application/json` |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| key | string | 필수 | `terms` \| `refund` \| `support` \| `intro` |

Body
```json
{ "ko": { "title": "이용 약관", "body": "..." }, "en": { "title": "Terms of Service", "body": "..." } }
```

## Response

200 OK
```json
{ "key": "terms", "versions": { "ko": { "title": "이용 약관", "body": "..." }, "en": { "title": "Terms of Service", "body": "..." } }, "updated_at": "2027-01-05T09:00:00Z" }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 404 NOT_FOUND: 존재하지 않는 `key`
- 422 VALIDATION: `ko`/`en`의 `title`/`body` 누락

## 비고

- operator 전용. univ_admin은 403.
- 제외: 해커톤 범위 외, 명세만 유지(수수료율은 상수 0.1 등). 콘텐츠는 시드 데이터로 대체.
