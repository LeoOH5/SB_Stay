# 구글 캘린더 연동 해제

- 번호: AU-08
- Method / Path: `DELETE /auth/google/calendar`
- 역할: buddy, guide
- 화면: B3
- 우선순위: 권장
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body: 없음

## Response

200 OK
```json
{ "calendar_connected": false }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: buddy/guide 역할이 아님

## 비고

- 처리: 저장된 refresh token으로 구글 `https://oauth2.googleapis.com/revoke` 호출(실패해도 계속) → `users.google_refresh_token=null`, `calendar_connected=false`.
- 멱등: 연동돼 있지 않아도 200 `{ "calendar_connected": false }`.
- 이미 만들어진 구글 캘린더 이벤트는 지우지 않는다(버디 캘린더에 남음). `booking_items.google_event_id`는 그대로 두되, 이후 BK-05 취소 시 `calendar_connected=false`면 삭제를 건너뛴다.
- 구글 로그인(AU-01) 자체는 유지된다. 로그인 연결 해제(계정 삭제)는 해커톤 범위 밖.
