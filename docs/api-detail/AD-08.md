# 외국인 숙박신고 내보내기

- 번호: AD-08
- Method / Path: `GET /admin/export/foreign-guests`
- 역할: operator
- 화면: A-06
- 우선순위: 권장
- 처리: 제외

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| from | date | 선택 | 체크인 기준 시작일 (YYYY-MM-DD) |
| to | date | 선택 | 체크인 기준 종료일 (YYYY-MM-DD) |

Body: 없음

## Response

200 OK (`Content-Type: text/csv`)
```csv
booking_code,name,nationality,passport_no,check_in,check_out,university
SB-20270112-001,Emma Clark,US,M12345678,2027-01-12,2027-01-14,A대학교
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 422 VALIDATION: 날짜 형식 오류 또는 `to < from`

## 비고

- operator 전용. univ_admin은 403.
- 제외: 해커톤 범위 외, 명세만 유지(수수료율은 상수 0.1 등).
