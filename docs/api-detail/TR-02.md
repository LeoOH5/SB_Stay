# 투어 코스 상세

- 번호: TR-02
- Method / Path: `GET /tours/{id}`
- 역할: 전체
- 화면: T4
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 투어 코스 ID |

Body: 없음

## Response

200 OK
```json
{ "id": 3, "title": "문인의 성북동 산책", "title_en": "Writers' Seongbuk Walk", "theme": "literature", "guide": { "id": 21, "name": "박○○", "license": "관광통역안내사", "languages": ["ko", "en"] }, "duration_min": 120, "price": 20000, "operating_days": ["sat", "sun"], "languages": ["en", "ko"], "meeting_point": "한성대입구역 5번 출구", "places": [ { "order": 1, "id": 101, "name": "최순우 옛집", "name_en": "Choi Sunu House", "lat": 37.59, "lng": 127.01, "stay_min": 20 } ] }
```

## Errors

- 404 NOT_FOUND: 존재하지 않는 투어 ID

## 비고

- 공개 조회. 장소 좌표·체류시간·가격·운영 요일은 DB 값 그대로이며 LLM이 생성하지 않음.
- `places`는 `order` 오름차순.
