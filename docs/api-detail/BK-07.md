# 체크인 안내 조회

- 번호: BK-07
- Method / Path: `GET /bookings/{id}/checkin-guide`
- 역할: tourist
- 화면: T6
- 우선순위: 필수
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID |

Body: 없음

## Response

200 OK
```json
{ "dorm": { "university": "A대학교", "building": "국제관", "address": "서울 성북구 ...", "lat": 37.59, "lng": 127.01 }, "check_in_time": "15:00", "procedure": ["정문에서 방문자 등록", "관리실에서 키 수령", "객실 이용 규칙 확인"], "emergency_contacts": [ { "name": "기숙사 관리실", "phone": "02-0000-0000" } ], "notes": "취사 금지, 22:00 이후 정숙" }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 본인 예약이 아님
- 404 NOT_FOUND: 예약 없음 또는 숙박 항목 없음

## 비고

- 권한: tourist 본인 예약만.
- 처리가 목업이므로 해커톤에서는 고정 응답 반환.
- 위치·시간 같은 사실 값은 DB(대학·객실) 값 사용.
