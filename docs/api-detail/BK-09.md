# 버디 채팅

- 번호: BK-09
- Method / Path: `GET /bookings/{id}/chat`
- 역할: tourist, buddy
- 화면: T6, B1
- 우선순위: 필수
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID (Path) |
| item_id | integer | 선택 | 버디 항목 ID (Query) |
| cursor | string | 선택 | 페이지 커서 (Query) |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "booking_item_id": 3, "sender_id": 1, "text": "Hi! Looking forward to it.", "translated_text": "안녕하세요! 기대돼요.", "created_at": "2027-01-11T10:00:00Z" } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 해당 예약의 tourist 본인 또는 담당 buddy가 아님
- 404 NOT_FOUND: 예약 또는 버디 항목 없음

## 비고

- 권한: tourist 본인, 해당 버디 항목의 buddy.
- 처리가 목업이므로 해커톤에서는 고정 응답 반환.
- `translated_text`는 자동 번역 예정 필드(해커톤에서는 고정 값).
