# 내 프로필 등록·수정

- 번호: BD-03
- Method / Path: `PUT /buddy/profile`
- 역할: buddy, guide
- 화면: B1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "major": "국어국문", "year": 3, "languages": ["ko", "en"], "interests": ["literature", "walking"], "intro": "성북동을 좋아하는 학생입니다.", "avatar": "illust_01.png", "hourly_fee": 15000, "school_email": "jiwoo@univ.ac.kr" }
```

## Response

200 OK
```json
{ "id": 31, "major": "국어국문", "year": 3, "languages": ["ko", "en"], "interests": ["literature", "walking"], "intro": "성북동을 좋아하는 학생입니다.", "avatar": "illust_01.png", "hourly_fee": 15000, "status": "pending", "school_email_verified": true }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음 또는 만료
- 403 FORBIDDEN: buddy/guide 역할이 아님
- 422 VALIDATION: 필수 필드 누락 또는 형식 오류(`year`, `hourly_fee`, `school_email`)

## 비고

- buddy/guide는 본인 프로필·요청·일정만 조회·수정 가능. 타인 데이터 접근 불가.
- 학교 이메일 인증은 목업: 해커톤에서는 형식만 검증하고 `school_email_verified: true` 고정 반환.
- 신규 등록 시 `status=pending`, 승인(`approved`)은 대학 관리자가 처리.
