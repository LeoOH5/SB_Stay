# 어드민 설정

- 번호: AD-10
- Method / Path: `PATCH /admin/settings`
- 역할: operator
- 화면: 설정
- 우선순위: 선택
- 처리: 제외

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |
| Content-Type | 필수 | `application/json` |

## Request

Path/Query params: 없음

Body
```json
{ "fee_rate": 0.1 }
```

## Response

200 OK
```json
{ "fee_rate": 0.1, "updated_at": "2027-01-05T09:00:00Z" }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 422 VALIDATION: `fee_rate`가 0~1 범위를 벗어나거나 숫자가 아님

## 비고

- operator 전용. univ_admin은 403.
- 제외: 해커톤 범위 외, 명세만 유지(수수료율은 상수 0.1 등).
