# 투어 리뷰

- 번호: TR-04
- Method / Path: `GET /tours/{id}/reviews`
- 역할: 전체
- 화면: T4
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 투어 코스 ID |

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "rating": 5, "text": "해설이 정말 좋았어요.", "created_at": "2027-01-20" } ], "average_rating": 4.8, "next_cursor": null }
```

## Errors

- 404 NOT_FOUND: 존재하지 않는 투어 ID

## 비고

- 해커톤에서는 고정 응답 반환. 실제 `reviews`(booking_item_id, rating, text) 집계는 구현하지 않음.
