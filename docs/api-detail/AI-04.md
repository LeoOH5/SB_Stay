# AI 동행 준비 자료

- 번호: AI-04
- Method / Path: `POST /ai/buddy-brief`
- 역할: buddy
- 화면: B1
- 우선순위: 선택
- 처리: 선택

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "booking_item_id": 3 }
```

## Response

200 OK
```json
{ "booking_item_id": 3, "places": [ { "name": "최순우 옛집", "name_en": "Choi Sunu House", "summary": "미술사학자 최순우가 살던 한옥", "tips": "운영시간 확인 후 입장, 신발 벗기" } ], "phrases": ["Please take off your shoes here.", "This house was built in the 1930s."] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 본인에게 배정된 버디 항목이 아님
- 404 NOT_FOUND: `booking_item_id` 없음
- 422 VALIDATION: `booking_item_id` 누락

## 비고

- 권한: buddy 본인에게 배정된 항목만.
- AI 엔드포인트: 사실 필드(가격·운영시간·좌표·가능 날짜)는 DB 값, LLM은 선택·순서·설명만 생성. 응답은 JSON.
- 해커톤 범위 외, 명세만 유지.
