# 개방 기간 수정

- 번호: DM-06
- Method / Path: `PATCH /admin/universities/{id}`
- 역할: univ_admin, operator
- 화면: A2
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` (univ_admin 또는 operator) |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 대학 ID (`universities.id`) |

Query params: 없음

Body
```json
{ "open_from": "2027-01-05", "open_to": "2027-02-20" }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| open_from | date | 필수 | 개방 시작일 |
| open_to | date | 필수 | 개방 종료일 |

## Response

200 OK
```json
{ "id": 1, "name": "A대학교", "name_en": "A University", "address": "서울 성북구 ...", "lat": 37.59, "lng": 127.01, "open_from": "2027-01-05", "open_to": "2027-02-20" }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음, 만료 또는 유효하지 않음
- 403 FORBIDDEN: 허용되지 않은 역할이거나 univ_admin이 타 대학 수정 시도
- 404 NOT_FOUND: 대학 없음
- 422 VALIDATION: 날짜 형식 오류 또는 `open_to < open_from`

## 비고

- 권한: univ_admin은 자기 `university_id` 대학만 수정, operator는 전체.
- 대학 단위 개방 기간만 수정. 객실별 기간은 DM-05에서 수정.
