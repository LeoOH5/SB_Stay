# 정산 내역 조회

- 번호: AD-06
- Method / Path: `GET /admin/settlements`
- 역할: operator
- 화면: 정산
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| from | date | 선택 | 정산 기간 시작일 (YYYY-MM-DD) |
| to | date | 선택 | 정산 기간 종료일 (YYYY-MM-DD) |
| party | string | 선택 | `university` \| `buddy` \| `guide` |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "party_type": "university", "party_id": 1, "party_name": "고려대학교", "period": { "from": "2027-01-05", "to": "2027-02-20" }, "gross": 2520000, "platform_fee": 252000, "net": 2268000, "status": "pending" } ], "next_cursor": null }
```
`status`: `pending` | `settled`

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 422 VALIDATION: 날짜 형식 오류 또는 `party` 값 오류

## 비고

- operator 전용. univ_admin은 403.
- 목업: 해커톤에서는 고정 응답 반환. (실제 구현 시 매출·수수료 등 숫자는 DB 집계값)
