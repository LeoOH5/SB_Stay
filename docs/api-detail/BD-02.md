# 버디 상세

- 번호: BD-02
- Method / Path: `GET /buddies/{id}`
- 역할: 전체
- 화면: T4c
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 버디 프로필 ID |

Body: 없음

## Response

200 OK
```json
{ "id": 31, "name": "지우", "university": "A대학교", "major": "국어국문", "year": 3, "languages": ["ko", "en", "ja"], "interests": ["literature", "walking"], "intro": "...", "avatar": "illust_01.png", "hourly_fee": 15000, "available_dates": ["2027-01-13", "2027-01-14"], "rating": 4.9, "review_count": 12, "reviews": [ { "rating": 5, "text": "친절했어요." } ] }
```

## Errors

- 404 NOT_FOUND: 존재하지 않거나 `approved`가 아닌 버디

## 비고

- `status=approved`인 버디만 노출. 그 외는 404.
- 가격(`hourly_fee`)·가능 날짜는 DB 값 그대로.
