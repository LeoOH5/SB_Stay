# 객실 상세 조회

- 번호: DM-03
- Method / Path: `GET /dorms/{id}`
- 역할: 전체
- 화면: T4b
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 대학명·규칙 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 객실 ID (`dorm_rooms.id`) |

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| check_in | date | 선택 | 체크인 날짜. 주면 해당 기간 기준 `available_rooms` 계산 |
| check_out | date | 선택 | 체크아웃 날짜 |

Body: 없음

## Response

200 OK
```json
{ "id": 10, "university": { "id": 1, "name": "고려대학교", "name_en": "Korea University", "address": "서울 성북구 ...", "lat": 37.59, "lng": 127.01 }, "building": "프런티어관", "room_type": "double", "price_per_night": 35000, "total_rooms": 20, "available_rooms": 12, "open_from": "2027-01-05", "open_to": "2027-02-20", "photos": ["..."], "rules": ["체크인 15:00 / 체크아웃 11:00", "취사 금지"], "active": true }
```

## Errors

- 404 NOT_FOUND: 객실이 없거나 `active=false`
- 422 VALIDATION: 날짜 형식 오류 또는 `check_out <= check_in`

## 비고

- 가격·기간·규칙·좌표는 DB 값 그대로. `available_rooms` = `total_rooms` − 해당 기간 `approved/confirmed` 예약 수.
- 날짜를 주지 않으면 개방 기간 전체 기준 값.
