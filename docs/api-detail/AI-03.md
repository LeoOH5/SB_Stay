# AI 버디 매칭

- 번호: AI-03
- Method / Path: `POST /ai/buddy-match`
- 역할: tourist
- 화면: T4c
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "language": "en", "date": "2027-01-13", "interests": ["literature"] }
```

## Response

200 OK
```json
{ "reason": "문학 관심·영어 가능한 순으로 골랐어요", "matches": [ { "buddy_id": 31, "score": 0.92, "reason": "시 전공, 영어 토론 동아리" } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist 외 역할
- 422 VALIDATION: `date` 형식 오류 또는 `language`/`interests` 값 오류

## 비고

- 권한: tourist 전용.
- AI 엔드포인트: 사실 필드(가격·운영시간·좌표·가능 날짜)는 DB 값, LLM은 선택·순서·설명만 생성. 응답은 JSON.
- 후보는 승인된(`approved`) 버디 중 해당 날짜 가능 + 언어 일치로 DB에서 먼저 거른 뒤 최대 3명 반환. 후보가 3명 미만이면 있는 만큼만 반환.
