# 어드민 예약 목록 조회

- 번호: AD-02
- Method / Path: `GET /admin/bookings`
- 역할: univ_admin, operator
- 화면: A1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| status | string | 선택 | 예약 상태 필터 (예: `requested`, `approved`, `confirmed`, `cancelled`) |
| type | string | 선택 | `dorm` \| `tour` \| `buddy` |
| university_id | integer | 선택 | 대학 ID 필터 (univ_admin은 본인 소속으로 고정) |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 101, "code": "SB-20270112-001", "status": "requested", "total_price": 140000, "platform_fee": 14000, "traveler": { "name": "Emma Clark" }, "created_at": "2027-01-05T09:30:00Z", "items": [ { "id": 201, "type": "dorm", "ref_id": 10, "status": "requested", "price": 140000, "university_id": 1 } ] } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: univ_admin/operator 외 역할
- 422 VALIDATION: `type` 값 오류 또는 잘못된 `cursor`

## 비고

- univ_admin은 같은 `university_id` 항목이 포함된 예약만, operator는 전체.
- 금액은 DB 값 그대로.
