# 내 예약 목록 조회

- 번호: BK-02
- Method / Path: `GET /bookings/me`
- 역할: tourist
- 화면: T6
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| scope | string | 선택 | `upcoming`(예정, 기본) 또는 `past`(지난) |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 501, "code": "SB-2027-0112", "status": "partially_approved", "total_price": 155000, "date_from": "2027-01-12", "date_to": "2027-01-15", "items": [ { "id": 1, "type": "dorm", "status": "approved", "price": 105000 }, { "id": 2, "type": "tour", "status": "confirmed", "price": 20000 }, { "id": 3, "type": "buddy", "status": "requested", "price": 30000 } ] } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist 외 역할
- 422 VALIDATION: `scope` 값 오류

## 비고

- 권한: tourist 본인 예약만.
- 상태값: `booking_items.status` = `requested` → `approved`|`rejected` → `confirmed` → `cancelled`, `bookings.status` = `requested` → `partially_approved` → `confirmed`|`cancelled`.
- `upcoming`은 종료일이 오늘 이후, `past`는 이전 예약.
