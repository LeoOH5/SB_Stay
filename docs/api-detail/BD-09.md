# 버디 지원 6단계 — 자격 두 경로 · 사전 교육 영상 · 퀴즈 (v3.7)

- 번호: BD-09
- Method / Path: `/buddy/apply/*`
- 역할: buddy (역할만 고른 지원자 포함)
- 화면: B06 자격 확인(대학 메일) · B06a 성북구 거주 · B07 약속 · B07a 교육 영상 · B08 퀴즈 · B09 프로필 · B10 심사
- 우선순위: 필수
- 처리: 구현

## 자격
대학생 + (a) 성북구 대학 재학 **또는** (b) 성북구 거주(어느 대학이든) + 대한민국 국적 + 만 19세 이상 + 약속 7개 + 사전 교육(영상 5개 → 퀴즈 8/10). 버디는 유료 역사 해설을 하지 않는다.

## 경로
| 단계 | Method / Path | Body → Response | 오류 |
|---|---|---|---|
| 상태 | `GET /buddy/apply` | → ApplyStatus (아래) | |
| 1 대학 메일 | `POST /buddy/apply/email` | `{email}` → `{sent, university, dev_code}` | 422 `NOT_SEONGBUK_SCHOOL` |
| 1 대학 메일 | `POST /buddy/apply/verify` | `{email, code, birth_date, korean_national}` → ApplyStatus (`eligibility: "school_email"`) | 422 `BAD_CODE` · `TOO_YOUNG` · `NOT_KOREAN_NATIONAL` |
| 1 성북구 거주 | `POST /buddy/apply/residence` | `{school_name, residence_proof_url, enrollment_proof_url, birth_date, korean_national}` → ApplyStatus (`eligibility: "residence"`) | 422 `PHOTO_URL`(사진이 `/uploads`의 `/media/...`가 아님) · `TOO_YOUNG` · `NOT_KOREAN_NATIONAL` · 409(이미 메일로 확인) |
| 2 약속 | `POST /buddy/apply/agree` | → ApplyStatus | 409 자격 확인 전 |
| 3 교육 영상 | `GET /buddy/apply/education` | → `{videos:[{id, title, topics, duration_sec, video_url, watched}], watched, total, done}` | |
| 3 교육 영상 | `POST /buddy/apply/education/{video_id}` | '다 봤어요' → 같은 모양 | 404 없는 영상 · 409 자격 확인 전 |
| 4 퀴즈 | `GET /buddy/apply/quiz` | → `{questions:[{id, text, options}]}` 10개 | 409 `EDUCATION_NOT_DONE` |
| 4 퀴즈 | `POST /buddy/apply/quiz` | `{answers:{id: 보기 번호}}` → `{score, total:10, passed, best_score}` | 409 `EDUCATION_NOT_DONE` |
| 5 프로필 | `PUT /buddy/profile` | BD-03 | |

- 거주 경로: 학교 이름이 성북구 대학 이름과 같으면 그 대학으로(`university_id`), 아니면 대학 없음(`school_name`만). 서류는 운영자가 승인(AD-04) 때 보고 확인한다.
- 교육 영상 id: `seongbuk_overview`(성북구 한눈에 보기) · `getting_around`(길 안내와 교통) · `safety`(안전과 응급) · `history_basics`(역사 기본 상식 — 해설이 아니라 기본 상식) · `promises`(버디 약속과 하지 말 것). 데모는 `video_url: null`(영상 준비 중).
- 퀴즈: 문제 13개 중 10개. 늘 q2(돈·선물 거절) · q3(버디는 역사 해설을 하지 않음) · q8(응급 번호) + 지원자 id로 정한 7개(다시 풀어도 같음). 낸 문제만 채점, 가장 높은 점수 저장.

## 개인정보
서류 사진도 `/media` 저장이라 주소를 아는 사람은 볼 수 있다(데모). 운영 전에는 비공개 저장소 + 서명 URL + 승인 뒤 삭제로 바꾼다.
