# 통합 예약 신청

- 번호: BK-01
- Method / Path: `POST /bookings`
- 역할: tourist
- 화면: T5
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |
| Idempotency-Key | 권장 | 중복 제출 방지용 고유 키. 같은 키로 재요청하면 같은 응답 반환 |

## Request

Path/Query params: 없음

Body
```json
{ "traveler": { "name": "Emma Clark", "nationality": "US", "email": "emma@example.com", "passport_no": "optional", "emergency_contact": "+1..." }, "items": [ { "type": "dorm", "ref_id": 10, "date_from": "2027-01-12", "date_to": "2027-01-15", "guests": 1 }, { "type": "tour", "ref_id": 3, "date": "2027-01-13", "time": "10:00" }, { "type": "buddy", "ref_id": 31, "date": "2027-01-13", "time": "14:00", "duration_min": 120 } ] }
```

## Response

201 Created
```json
{ "id": 501, "code": "SB-2027-0112", "status": "requested", "total_price": 155000, "platform_fee": 15500, "items": [ { "id": 1, "type": "dorm", "status": "requested", "price": 105000 }, { "id": 2, "type": "tour", "status": "confirmed", "price": 20000 }, { "id": 3, "type": "buddy", "status": "requested", "price": 30000 } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist 외 역할
- 404 NOT_FOUND: `ref_id`에 해당하는 객실·투어·버디 없음
- 409 CONFLICT: 잔여 객실 없음, 투어 운영일 아님, 버디 가능 날짜 아님
- 422 VALIDATION: traveler 필수값 누락, 날짜·시간 형식 오류, `items` 비어 있음

## 비고

- 권한: tourist 전용. 예약자는 토큰의 사용자.
- 상태값: `booking_items.status` = `requested` → `approved`|`rejected` → `confirmed` → `cancelled`, `bookings.status` = `requested` → `partially_approved` → `confirmed`|`cancelled`.
- 규칙: 투어 항목은 즉시 `confirmed`. 모든 항목이 `approved`/`confirmed`면 booking `confirmed`. 하나라도 `rejected`면 해당 항목만 제외하고 관광객에게는 상태값으로만 알림(알림 발송은 MVP 제외).
- 가격은 DB 값으로 서버가 계산. `platform_fee`는 `total_price`의 10%(상수).
- `Idempotency-Key` 권장: 같은 키의 재요청은 새 예약을 만들지 않고 같은 응답 반환.
