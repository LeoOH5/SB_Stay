# 알림 목록 조회

- 번호: BK-10
- Method / Path: `GET /notifications`
- 역할: tourist, buddy
- 화면: T6
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "type": "approved", "booking_id": 501, "item_id": 1, "message": "숙박 요청이 승인되었습니다.", "read": false, "created_at": "2027-01-10T09:30:00Z" } ], "next_cursor": null }
```
`type`: `approved` | `confirmed` | `rejected` | `cancelled`

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist/buddy 외 역할

## 비고

- 권한: 본인 알림만.
- 처리가 목업이므로 해커톤에서는 고정 응답 반환.
- 알림 발송(푸시·이메일)은 MVP 제외, 상태값 목록만 제공.
