# 내 정보 조회

- 번호: AU-03
- Method / Path: `GET /auth/me`
- 역할: 전체
- 화면: 공통
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body: 없음

## Response

200 OK
```json
{ "id": 1, "email": "emma@example.com", "name": "Emma Clark", "role": "tourist", "university_id": null, "language": "en" }
```
`role`: `tourist` | `buddy` | `guide` | `univ_admin` | `operator`

## Errors

- 401 UNAUTHORIZED: 토큰 없음, 만료 또는 유효하지 않음

## 비고

- 토큰의 사용자 본인 정보만 반환. `password_hash`는 절대 노출하지 않음.
- 앱 시작 시 토큰 유효성 확인과 역할별 화면 분기에 사용.
