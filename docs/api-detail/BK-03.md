# 예약 상세 조회

- 번호: BK-03
- Method / Path: `GET /bookings/{id}`
- 역할: tourist(본인), 공급자(해당 항목), admin
- 화면: T6, A1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID |

Body: 없음

## Response

200 OK
```json
{ "id": 501, "code": "SB-2027-0112", "status": "partially_approved", "total_price": 155000, "platform_fee": 15500, "paid_at": null, "traveler": { "name": "Emma Clark", "nationality": "US", "email": "emma@example.com", "emergency_contact": "+1..." }, "items": [ { "id": 1, "type": "dorm", "ref_id": 10, "date_from": "2027-01-12", "date_to": "2027-01-15", "status": "approved", "price": 105000, "reject_reason": null }, { "id": 2, "type": "tour", "ref_id": 3, "date": "2027-01-13", "time": "10:00", "status": "confirmed", "price": 20000, "reject_reason": null }, { "id": 3, "type": "buddy", "ref_id": 31, "date": "2027-01-13", "time": "14:00", "status": "requested", "price": 30000, "reject_reason": null } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 본인 예약이 아니거나 해당 항목의 공급자·admin이 아님
- 404 NOT_FOUND: 예약 없음

## 비고

- 권한: tourist 본인, 해당 항목의 공급자, admin(`univ_admin`은 같은 `university_id`, `operator`는 전체).
- 공급자(buddy/guide/univ_admin)에게는 자신이 담당하는 항목만 `items`에 포함.
- 상태값: `booking_items.status` = `requested` → `approved`|`rejected` → `confirmed` → `cancelled`, `bookings.status` = `requested` → `partially_approved` → `confirmed`|`cancelled`.
