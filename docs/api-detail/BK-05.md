# 예약 취소

- 번호: BK-05
- Method / Path: `POST /bookings/{id}/cancel`
- 역할: tourist, operator
- 화면: T6, A1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID |

Body
```json
{ "reason": "일정 변경" }
```

바디는 선택(`reason`).

## Response

200 OK
```json
{ "id": 501, "code": "SB-2027-0112", "status": "cancelled", "items": [ { "id": 1, "type": "dorm", "status": "cancelled" }, { "id": 2, "type": "tour", "status": "cancelled" }, { "id": 3, "type": "buddy", "status": "cancelled" } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist 본인 예약이 아님 또는 권한 없는 역할
- 404 NOT_FOUND: 예약 없음
- 409 CONFLICT: 이미 취소됨

## 비고

- 권한: tourist 본인 예약, operator 전체.
- 취소 시 booking과 모든 항목 상태가 `cancelled`로 변경. 환불은 해커톤에서 처리하지 않음.
- 구글 캘린더: 항목에 google_event_id 있으면 이벤트 삭제(services/google_calendar.py, 공급자가 `calendar_connected`일 때). 실패해도 취소는 성공(로그만).
