# 버디 승인·제재

- 번호: AD-04
- Method / Path: `PATCH /admin/buddies/{id}`
- 역할: operator (v3.3부터)
- 화면: A03 회원·버디 승인
- 우선순위: 필수
- 처리: 부분 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |
| Content-Type | 필수 | `application/json` |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | buddy_profile ID |

Body
```json
{ "action": "approve" }
```
`action`: `approve` | `suspend`

## Response

200 OK — AdminBuddyRow ([AD-03](AD-03.md)). 승인하면 `approved_on` = 오늘(처음 한 번). 승인 후 첫 달은 등급 기본.

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: 권한 없음 또는 다른 대학 소속 버디 (univ_admin)
- 404 NOT_FOUND: 버디 프로필 없음
- 409 NOT_READY: 승인 조건이 빠짐. message에 빠진 항목, 예: "아직 승인할 수 없어요: 성북구 주소 증빙, 교육 영상 4/5"
- 422 VALIDATION: `action` 누락 또는 허용값 외

## 비고

- 승인 조건(v3.7, `services/eligibility.missing_for_approval`):
  - 자격 경로 하나: 성북구 대학 메일 인증, 또는 성북구 거주 — 주소 증빙·재학 증명 사진 두 장(운영자가 A03에서 썸네일을 보고 승인하면 확인한 것)
  - 한국 국적 확인 · 만 19세 · 버디 약속 동의 · 교육 영상 5개 · 교육 퀴즈 8점 이상
- 빠진 항목 문구: "성북구 주소 증빙" · "재학 증명" · "자격 확인(성북구 대학 메일 또는 성북구 거주)" · "한국 국적 확인" · "만 19세 확인" · "버디 약속 동의" · "교육 영상 n/5" · "교육 퀴즈 8점 이상"
- `suspend`는 상태값(`suspended`) 변경만 수행.
