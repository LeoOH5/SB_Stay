# 투어 코스 목록

- 번호: TR-01
- Method / Path: `GET /tours`
- 역할: 전체
- 화면: 투어 목록
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| theme | string | 선택 | 테마 필터 (예: `literature`, `independence`) |
| date | date | 선택 | 참가 날짜 (YYYY-MM-DD). 운영 요일에 맞는 코스만 |
| language | string | 선택 | 가이드 언어 (`ko`, `en` 등) |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 3, "title": "문인의 성북동 산책", "title_en": "Writers' Seongbuk Walk", "theme": "literature", "guide": { "id": 21, "name": "박○○" }, "duration_min": 120, "price": 20000, "operating_days": ["sat", "sun"], "languages": ["en", "ko"], "meeting_point": "한성대입구역 5번 출구" } ], "next_cursor": null }
```

## Errors

- 422 VALIDATION: `date` 형식 오류

## 비고

- 공개 조회. 가격·소요시간·운영 요일은 DB 값 그대로.
- `date`가 주어지면 해당 요일이 `operating_days`에 포함된 코스만 반환.

## v3.5 걸리는 시간은 계산값
코스에 `duration_min`(계산값) · `stay_min_total` · `walk_m_total` · `walk_min_total` · `walk_complete` · `legs[]`(`from_place_id, to_place_id, walk_m, walk_min`)가 붙고, `places[]`에 `photo_url` · `photo_credit`이 붙는다. 목록(TR-01)과 상세(TR-02) 모두. 계산 규칙은 `docs/v3/CONTRACT.md` §14.

## v3.8 실제 도보 경로(OpenStreetMap)
`legs[]`에 `source`(`"route"` = OpenStreetMap 실제 도보 경로 · `"estimate"` = 직선 × 1.3 추정 · 좌표 없으면 `null`)와 `path`(`route`일 때 `[[위도, 경도], ...]`, from → to 방향, 아니면 `null`)가 붙고, 코스에 `route_source`(`"route"` 모든 구간 실제 · `"estimate"` 실제 경로 없음 · `"mixed"` 섞임)가 붙는다. 실제 경로가 있으면 `walk_m`은 그 거리(10 m 반올림), `walk_min`은 같은 4 km/h로 올림. 경로는 DB `walk_routes`(미리 받아 둔 값)에서 읽고 요청 중에 외부 서버를 부르지 않는다. 화면에 `path`를 그리면 '경로 © OpenStreetMap'을 표시한다. 규칙은 `docs/v3/CONTRACT.md` §17.
```json
{ "legs": [ { "from_place_id": 111, "to_place_id": 102, "walk_m": 520, "walk_min": 8, "source": "route", "path": [[37.59251, 126.997056], [37.594, 126.996], [37.595107, 126.994855]] } ], "route_source": "route" }
```
