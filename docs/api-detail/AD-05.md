# 회원 목록 조회

- 번호: AD-05
- Method / Path: `GET /admin/users`
- 역할: operator
- 화면: 회원 관리
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| role | string | 선택 | `tourist` \| `buddy` \| `guide` |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "email": "emma@example.com", "name": "Emma Clark", "role": "tourist", "university_id": null, "language": "en", "created_at": "2027-01-02T08:00:00Z" } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 422 VALIDATION: `role` 값 오류 또는 잘못된 `cursor`

## 비고

- operator 전용. univ_admin은 403.
- 목업: 해커톤에서는 고정 응답 반환.
