# 장소 상세

- 번호: TR-03
- Method / Path: `GET /places/{id}`
- 역할: 전체
- 화면: T4
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 장소 ID |

Body: 없음

## Response

200 OK
```json
{ "id": 101, "name": "최순우 옛집", "name_en": "Choi Sunu House", "lat": 37.59, "lng": 127.01, "address": "서울 성북구 성북로15길 9", "hours": "10:00-17:00", "closed_days": ["mon"], "fee": 0, "need_reservation": false, "stay_min": 20, "tags": ["literature", "house"] }
```

## Errors

- 404 NOT_FOUND: 존재하지 않는 장소 ID

## 비고

- 공개 조회. 운영시간·휴관일·요금·좌표는 DB 값 그대로(사실 필드는 LLM이 만들지 않음).
- 예시 값은 샘플.
