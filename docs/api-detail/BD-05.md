# 내게 온 요청 목록

- 번호: BD-05
- Method / Path: `GET /buddy/requests`
- 역할: buddy, guide
- 화면: B1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| status | string | 선택 | `requested`(기본) / `approved` / `rejected` / `confirmed` / `cancelled` |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 501, "booking_code": "SB-20270112-A1", "type": "buddy", "ref_id": 31, "date_from": "2027-01-13", "date_to": "2027-01-13", "time": "14:00", "price": 30000, "status": "requested", "tourist": { "id": 1, "name": "Emma Clark", "language": "en" } } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음 또는 만료
- 403 FORBIDDEN: buddy/guide 역할이 아님
- 422 VALIDATION: 허용되지 않는 `status` 값

## 비고

- buddy/guide는 본인 프로필·요청·일정만 조회·수정 가능. 타인 데이터 접근 불가.
- `booking_items` 중 본인에게 지정된 `type=buddy|tour` 항목만 반환. 숙박(dorm) 항목은 제외.
- 상태 흐름: requested → approved|rejected → confirmed → cancelled.
- 관광객 정보는 이름·언어 등 요약만 노출.
