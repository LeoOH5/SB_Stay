# 투어 코스 관리

- 번호: AD-07
- Method / Path: `GET /admin/tours`
- 역할: operator
- 화면: 투어 관리
- 우선순위: 권장
- 처리: 시드 대체

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 3, "title": "성북동 근현대사 투어", "title_en": "Seongbuk-dong Modern History Tour", "theme": "history", "guide": { "id": 2, "name": "박해설" }, "price": 30000, "operating_days": ["sat", "sun"], "active": true } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: operator 외 역할 (univ_admin 포함)
- 422 VALIDATION: 잘못된 `cursor`

## 비고

- operator 전용. univ_admin은 403.
- 시드 대체: 시드 데이터 조회만 제공하며 생성·수정은 지원하지 않음.
