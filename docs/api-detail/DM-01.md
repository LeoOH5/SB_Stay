# 대학 목록 조회

- 번호: DM-01
- Method / Path: `GET /universities`
- 역할: 전체
- 화면: T4b
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 대학명 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "name": "A대학교", "name_en": "A University", "address": "서울 성북구 ...", "lat": 37.59, "lng": 127.01, "open_from": "2027-01-05", "open_to": "2027-02-20" } ], "next_cursor": null }
```

## Errors

- 422 VALIDATION: `cursor` 형식 오류

## 비고

- 위치·개방 기간은 `universities` DB 값 그대로(LLM이 만들지 않음).
- 지도 표시는 `lat`, `lng` 사용.
