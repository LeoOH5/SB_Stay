# 추천 패키지 조회

- 번호: HM-01
- Method / Path: `GET /packages`
- 역할: 전체
- 화면: T1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 제목·요약 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 1, "title": "문인의 성북동 2박 3일", "title_en": "Writers' Seongbuk 3 Days", "summary": "기숙사 숙박 + 문인 산책 투어 + 버디 동행", "price_from": 155000, "days": 3, "items": [ { "type": "dorm", "ref_id": 10, "title": "고려대학교 프런티어관" }, { "type": "tour", "ref_id": 3, "title": "문인의 성북동 산책" }, { "type": "buddy", "ref_id": 31, "title": "버디와 캠퍼스·동네 걷기" } ], "cover": "pkg_01.jpg" } ], "next_cursor": null }
```
`items[].type`: `dorm` | `tour` | `buddy`

## Errors

- 422 VALIDATION: `cursor` 형식 오류

## 비고

- 시드 데이터. 홈 화면 추천용이며 예약은 구성 항목(`ref_id`)으로 BK-01에 담아 진행.
- `price_from` 등 가격은 DB 값 그대로.
