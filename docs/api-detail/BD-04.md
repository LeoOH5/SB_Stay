# 가능 날짜 교체

- 번호: BD-04
- Method / Path: `PUT /buddy/availability`
- 역할: buddy, guide
- 화면: B1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "dates": ["2027-01-13", "2027-01-14", "2027-01-20"] }
```

## Response

200 OK
```json
{ "dates": ["2027-01-13", "2027-01-14", "2027-01-20"] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음 또는 만료
- 403 FORBIDDEN: buddy/guide 역할이 아님
- 422 VALIDATION: 날짜 형식 오류 또는 과거 날짜 포함
- 409 CONFLICT: 이미 확정(confirmed)된 일정의 날짜를 제외하려는 경우

## 비고

- buddy/guide는 본인 프로필·요청·일정만 조회·수정 가능. 타인 데이터 접근 불가.
- 전체 교체: 기존 `buddy_availability`를 삭제하고 요청 `dates`로 대체. 빈 배열이면 전체 삭제.
