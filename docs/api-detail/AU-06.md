# 역할 선택 (첫 로그인)

- 번호: AU-06
- Method / Path: `PATCH /auth/me/role`
- 역할: 전체 (tourist · buddy · guide 간 선택)
- 화면: T0 (역할 선택 단계)
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "role": "buddy", "university_id": 1 }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| role | string | 필수 | `tourist` \| `buddy` \| `guide`. `univ_admin`·`operator`는 선택 불가(시드 계정만) |
| university_id | integer | 조건부 | `role`이 `buddy`/`guide`면 필수(DM-01 목록에서 선택). `tourist`면 무시되고 null |

## Response

200 OK
```json
{ "id": 7, "email": "jiwoo@gmail.com", "name": "지우", "avatar_url": "https://lh3.googleusercontent.com/a/...", "role": "buddy", "university_id": 1, "language": "ko", "calendar_connected": false }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 현재 역할이 `univ_admin`/`operator`(변경 불가), 또는 `univ_admin`/`operator`로 바꾸려는 요청
- 404 NOT_FOUND: `university_id`에 해당하는 대학 없음
- 409 CONFLICT: 이미 `buddy`/`guide` 프로필(BD-03)이 있거나 예약·요청이 있는 계정의 역할 변경
- 422 VALIDATION: `role` 값 오류, `buddy`/`guide`인데 `university_id` 누락

## 비고

- AU-01 응답의 `needs_role_setup=true`일 때 T0 역할 선택 화면에서 호출. 구글로 새로 만든 계정은 `role=tourist`로 시작하므로 관광객은 이 호출을 생략해도 된다.
- `buddy`/`guide` 선택 시 `users.university_id`만 저장하고 프로필은 BD-03에서 등록 → 대학 승인(AD-04)까지는 `pending`.
- 역할·대학 변경은 프로필·예약이 생기기 전까지만 허용(409). 그 뒤 변경은 운영자 작업.
- 응답 형식은 AU-03과 같다.
