# 무료 코스 완료 설문 — v3.4

- 번호: TR-05
- Method / Path: `POST /tours/{id}/survey`
- 역할: tourist
- 화면: T08c 코스 완료 설문 ("코스 다 걸었어요" 뒤)
- 우선순위: 권장
- 처리: 구현

## Request

Body
```json
{ "satisfaction": 4, "pain": "no_help", "want_buddy": true }
```
- `satisfaction` 1~5
- `pain` (가장 불편했던 점): `ads` 광고가 귀찮았어요 · `question_limit` 질문 3번이 모자랐어요 · `route_fit` 동선이 내 숙소·시간과 안 맞았어요 · `no_help` 길을 잃었을 때 물어볼 사람이 없었어요 · `none` 딱히 없었어요
- `want_buddy` 다음엔 버디와 걸어 볼래요? (네/아니요)

## Response

201 Created
```json
{ "id": 1, "tour_id": 3, "satisfaction": 4, "pain": "no_help", "want_buddy": true, "plan": "free", "created_at": "2027-01-14T05:00:00Z" }
```
`plan`은 낸 때의 이용 방식(AU-09). `course_surveys` 표에 쌓인다. 할인 같은 약속은 응답에 없다.

## Errors

- 401 UNAUTHORIZED · 403 FORBIDDEN(관광객이 아님)
- 404 NOT_FOUND: 코스 없음
- 422 VALIDATION: 만족도 범위 밖, 모르는 `pain` 코드
