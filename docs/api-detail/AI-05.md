# AI 다국어 안내문 초안

- 번호: AI-05
- Method / Path: `POST /ai/translate-notice`
- 역할: operator
- 화면: 어드민
- 우선순위: 선택
- 처리: 제외

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "text": "체크인은 15:00부터 가능합니다. 취사는 금지입니다.", "target_languages": ["en", "ja"] }
```

## Response

200 OK
```json
{ "drafts": { "en": "Check-in is available from 15:00. Cooking is not allowed.", "ja": "チェックインは15:00からです。調理は禁止です。" } }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: operator 외 역할
- 422 VALIDATION: `text` 누락 또는 `target_languages` 비어 있음

## 비고

- 권한: operator 전용.
- AI 엔드포인트: 사실 필드(가격·운영시간·좌표·가능 날짜)는 DB 값, LLM은 선택·순서·설명만 생성. 응답은 JSON.
- 초안일 뿐 저장·게시는 운영자가 별도로 수행.
- 해커톤 범위 외, 명세만 유지.
