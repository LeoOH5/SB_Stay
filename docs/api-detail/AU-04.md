# 언어·통화 설정 / 프로필 수정

- 번호: AU-04
- Method / Path: `PATCH /users/me`
- 역할: 전체
- 화면: 마이페이지
- 우선순위: 필수
- 처리: 구현(언어만)

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body (보낸 필드만 수정)
```json
{ "language": "en", "currency": "USD", "name": "Emma Clark" }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| language | string | 선택 | `ko` 또는 `en` |
| currency | string | 선택 | 통화 코드. 해커톤에서는 무시 |
| name | string | 선택 | 이름. 해커톤에서는 무시 |

## Response

200 OK
```json
{ "id": 1, "email": "emma@example.com", "name": "Emma Clark", "role": "tourist", "university_id": null, "language": "en" }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음, 만료 또는 유효하지 않음
- 422 VALIDATION: `language`가 `ko`/`en`이 아님

## 비고

- 해커톤 범위: `users.language`만 반영. `currency`, `name`은 받되 무시 가능.
- 본인 계정만 수정 가능. `role`, `university_id`, `email`은 변경 불가.
