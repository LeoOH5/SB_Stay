# AI 역사 스토리 (RAG)

- 번호: AI-02
- Method / Path: `POST /ai/story`
- 역할: 전체
- 화면: T4
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "place_id": 103, "question": "Why does this house face north?", "language": "en" }
```

## Response

200 OK
```json
{ "answer": "He refused to face the Japanese Government-General building to the south…", "sources": [ { "title": "성북구 문화관광 자료", "url": "..." } ], "grounded": true }
```
`question` 생략 시 장소 소개 이야기 반환. `grounded=false`면 프론트는 "자료에 없다" 안내.

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 404 NOT_FOUND: `place_id`에 해당하는 장소 없음
- 422 VALIDATION: `place_id` 누락 또는 `language` 값 오류

## 비고

- 권한: 로그인한 모든 역할.
- AI 엔드포인트: 사실 필드(가격·운영시간·좌표·가능 날짜)는 DB 값, LLM은 선택·순서·설명만 생성. 응답은 JSON.
- RAG 문서(`places.story_doc`, `sources`) 밖의 질문이면 `grounded=false`로 응답하고 "자료에 없다"로 안내. 출처(`sources`)를 항상 포함.
