# 소속 버디 목록 조회

- 번호: AD-03
- Method / Path: `GET /admin/buddies`
- 역할: operator (v3.3부터)
- 화면: A03 회원·버디 승인
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| status | string | 선택 | `pending` \| `approved` \| `suspended` |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

- v3.7: `eval_rating·eval_walks·eval_reviews`(방학 두 개 합산) 삭제 → `eval_month`(지난달) · `last_month_walks`(지난달 완료 동행, 누적 아님) · `total_reviews` · `avg_rating`(누적) · `evaluated_for`(지금 등급을 정한 평가 달) · `approved_on`.
- 자격: `eligibility`(school_email | residence), 거주 경로는 `school_name`과 서류 두 장(`/media/...`면 사진, 아니면 예전 데모 값 → 화면 자리 표시), 교육 영상 `videos_watched / videos_total`.

### 등급 다시 계산 `POST /admin/buddies/recompute-grades` (operator)
오늘이 든 달 1일 평가(지난달 동행)를 아직 안 한 버디만 평가하고 휴면을 판정한다. 바뀐 버디 행만 `{items:[...]}`. 같은 달에 다시 눌러도 또 오르지 않는다. 스크립트 `scripts/recompute_grades.py [날짜]`도 같다.

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: univ_admin/operator 외 역할
- 422 VALIDATION: `status` 값 오류 또는 잘못된 `cursor`

## 비고
