# 소속 버디 목록 조회

- 번호: AD-03
- Method / Path: `GET /admin/buddies`
- 역할: univ_admin, operator
- 화면: A2
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| status | string | 선택 | `pending` \| `approved` \| `suspended` |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 5, "user_id": 12, "name": "김민준", "university_id": 1, "major": "사학과", "year": 3, "languages": ["ko", "en"], "interests": ["history", "food"], "status": "pending", "created_at": "2027-01-03T10:00:00Z" } ], "next_cursor": null }
```

## Errors

- 401 UNAUTHORIZED: 토큰 누락 또는 만료
- 403 FORBIDDEN: univ_admin/operator 외 역할
- 422 VALIDATION: `status` 값 오류 또는 잘못된 `cursor`

## 비고

- univ_admin은 같은 `university_id` 버디만, operator는 전체.
