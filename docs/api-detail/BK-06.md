# 결제

- 번호: BK-06
- Method / Path: `POST /bookings/{id}/pay`
- 역할: tourist
- 화면: T5
- 우선순위: 필수
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |
| Idempotency-Key | 권장 | 중복 제출 방지용 고유 키. 같은 키로 재요청하면 같은 응답 반환 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID |

Body: 없음

## Response

200 OK
```json
{ "id": 501, "status": "paid", "paid_at": "2027-01-10T09:00:00Z", "payment": { "method": "mock", "amount": 155000 } }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 본인 예약이 아님
- 404 NOT_FOUND: 예약 없음
- 409 CONFLICT: 이미 결제됨 또는 취소된 예약

## 비고

- 권한: tourist 본인 예약만.
- 처리가 목업이므로 해커톤에서는 고정 응답 반환. 호출 즉시 `paid` 처리하고 `paid_at` 기록.
- `Idempotency-Key` 권장: 같은 키의 재요청은 같은 응답 반환(이중 결제 방지).
