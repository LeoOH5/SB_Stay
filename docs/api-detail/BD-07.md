# 활동 내역·정산

- 번호: BD-07
- Method / Path: `GET /buddy/earnings`
- 역할: buddy, guide
- 화면: 활동 내역
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Path/Query params: 없음

Body: 없음

## Response

200 OK
```json
{ "period": "2027-01", "total_sessions": 8, "total_earned": 240000, "settled": 150000, "pending": 90000, "items": [ { "booking_item_id": 501, "date": "2027-01-13", "type": "buddy", "title": "버디와 캠퍼스·동네 걷기", "amount": 30000, "settled": true } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음 또는 만료
- 403 FORBIDDEN: buddy/guide 역할이 아님

## 비고

- buddy/guide는 본인 프로필·요청·일정만 조회·수정 가능. 타인 데이터 접근 불가.
- 해커톤에서는 고정 응답 반환. 실제 정산 계산·지급은 구현하지 않음.
