# 버디 목록

- 번호: BD-01
- Method / Path: `GET /buddies`
- 역할: 전체
- 화면: T4c
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| language | string | 선택 | 구사 언어 (`ko`, `en`, `ja` 등) |
| date | date | 선택 | 가능 날짜 (YYYY-MM-DD) |
| interest | string | 선택 | 관심사 태그 |
| major | string | 선택 | 전공 |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 31, "name": "지우", "university": "A대학교", "major": "국어국문", "year": 3, "languages": ["ko", "en", "ja"], "interests": ["literature", "walking"], "intro": "...", "avatar": "illust_01.png", "available_dates": ["2027-01-13", "2027-01-14"], "rating": 4.9, "review_count": 12 } ], "next_cursor": null }
```

## Errors

- 422 VALIDATION: `date` 형식 오류

## 비고

- `status=approved`인 버디만 노출 (pending/suspended 제외).
- `date` 필터는 `buddy_availability`에 해당 날짜가 있는 버디만.
- 연락처 등 개인정보는 노출하지 않음(`avatar`는 일러스트).
