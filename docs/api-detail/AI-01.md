# AI 여행 설계

- 번호: AI-01
- Method / Path: `POST /ai/plan`
- 역할: tourist
- 화면: T2→T3
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "check_in": "2027-01-12", "check_out": "2027-01-15", "budget": 200000, "interests": ["literature", "independence"], "with_buddy": true, "language": "en", "note": "I love Korean poetry" }
```

## Response

200 OK (후보는 DB에서 날짜·가격·운영일로 먼저 거르고 LLM은 선택·순서·설명만)
```json
{ "plan_id": "pl_8f2", "reason": "문학·독립운동 관심에 맞춰 한용운·이태준이 살던 성북동 코스를 넣었어요. 숙소에서 걸어서 20분.", "total_price": 155000, "days": [ { "date": "2027-01-12", "items": [ { "time": "15:00", "type": "dorm", "ref_id": 10, "title": "고려대학교 프런티어관 체크인", "price": 105000 } ] }, { "date": "2027-01-13", "items": [ { "time": "10:00", "type": "tour", "ref_id": 3, "title": "문인의 성북동 산책", "price": 20000 }, { "time": "14:00", "type": "buddy", "ref_id": 31, "title": "버디와 캠퍼스·동네 걷기", "price": 30000 } ] }, { "date": "2027-01-14", "items": [ { "time": null, "type": "free", "ref_id": null, "title": "정릉 · 선잠박물관 추천", "price": 0 } ] } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: tourist 외 역할
- 422 VALIDATION: check_in/check_out 형식 오류 또는 `check_out <= check_in`, budget 음수

## 비고

- 권한: tourist 전용.
- AI 엔드포인트: 사실 필드(가격·운영시간·좌표·가능 날짜)는 DB 값, LLM은 선택·순서·설명만 생성. 응답은 JSON.
- 조건에 맞는 후보가 없으면 `days`의 해당 날짜는 `type: free` 항목으로 채움. 이 응답은 추천일 뿐 예약은 BK-01로 별도 생성.

## v3.8 자유 장소 순서는 코드가 정한다
- 하루에 자유 장소가 여러 곳이면(`type: free`, 지금은 하루 2곳) **걷는 거리가 가장 짧은 순서**(`services/courses.best_order`)로 놓는다. 거리는 저장한 OpenStreetMap 실제 도보 경로 → 없으면 직선 × 1.3. LLM이 `free_place_ids`를 어떤 순서로 내든 **어느 장소인지(고르기)**만 쓰고, 그날 순서는 코드가 다시 정한다(두 곳이면 어느 쪽이든 거리가 같아 장소 id 순).
- free 항목에 `place_ids`(걷는 순서), `walk_m`(사이 걷는 거리, 10 m 단위), `walk_min`(사이 걷는 분)이 붙고 `meta` 끝에 " · 사이 도보 N분"(en " · N min walk between"). 한 곳이거나 좌표가 없으면 `walk_*`는 null.
- 무료 코스 장소는 정해 둔 코스 순서(`tour_places.seq`) 그대로 (무료 이용은 코스 순서가 고정).
```json
{ "time": null, "type": "free", "ref_id": null, "title": "길상사 · 북정마을 추천", "price": 0, "meta": "자유 일정 · AI 제안 · 사이 도보 14분", "place_ids": [104, 120], "walk_m": 880, "walk_min": 14 }
```
