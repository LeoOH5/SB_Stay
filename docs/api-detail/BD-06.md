# 확정 일정 조회

- 번호: BD-06
- Method / Path: `GET /buddy/schedule`
- 역할: buddy, guide
- 화면: B1
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>`. buddy 또는 guide 역할 |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답 텍스트 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| range | string | 선택 | `today` 또는 `week`(기본, 이번 주) |

Body: 없음

## Response

200 OK
```json
{ "range": "week", "items": [ { "id": 501, "booking_code": "SB-20270112-A1", "type": "buddy", "date": "2027-01-13", "time": "14:00", "title": "버디와 캠퍼스·동네 걷기", "meeting_point": "한성대입구역 5번 출구", "status": "confirmed", "tourist": { "name": "Emma Clark", "language": "en" } } ] }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음 또는 만료
- 403 FORBIDDEN: buddy/guide 역할이 아님
- 422 VALIDATION: 허용되지 않는 `range` 값

## 비고

- buddy/guide는 본인 프로필·요청·일정만 조회·수정 가능. 타인 데이터 접근 불가.
- `status=confirmed`인 본인 항목만 날짜·시간 오름차순으로 반환.
