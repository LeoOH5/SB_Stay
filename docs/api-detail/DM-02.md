# 객실 목록 조회

- 번호: DM-02
- Method / Path: `GET /dorms`
- 역할: 전체
- 화면: T4b
- 우선순위: 필수
- 처리: 구현

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 공개 조회이므로 없어도 됨 |
| Accept-Language | 선택 | `ko` 또는 `en`. 대학명·규칙 언어 |

## Request

Query params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| university_id | integer | 선택 | 대학 ID로 필터 |
| check_in | date | 선택 | 체크인 날짜 (YYYY-MM-DD) |
| check_out | date | 선택 | 체크아웃 날짜 (YYYY-MM-DD) |
| guests | integer | 선택 | 인원 수 (기본 1) |
| cursor | string | 선택 | 페이지 커서 |

Body: 없음

## Response

200 OK
```json
{ "items": [ { "id": 10, "university": { "id": 1, "name": "고려대학교", "name_en": "Korea University" }, "building": "프런티어관", "room_type": "double", "price_per_night": 35000, "open_from": "2027-01-05", "open_to": "2027-02-20", "available_rooms": 12, "photos": ["..."], "rules": ["체크인 15:00 / 체크아웃 11:00", "취사 금지"] } ], "next_cursor": null }
```

## Errors

- 422 VALIDATION: 날짜 형식 오류 또는 `check_out <= check_in`

## 비고

- `active=true`이고 개방 기간이 요청 기간을 포함하는 객실만 반환. `available_rooms` = `total_rooms` − 해당 기간 `approved/confirmed` 예약 수.
- 가격·기간은 DB 값 그대로.
