# 회원가입

- 번호: AU-02
- Method / Path: `POST /auth/signup`
- 역할: tourist
- 화면: T0
- 우선순위: 필수
- 처리: 구현(단순화)

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 선택 | `Bearer <JWT>`. 가입 전이므로 불필요 |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 에러 메시지 언어 |

## Request

Path/Query params: 없음

Body
```json
{ "email": "emma@example.com", "password": "demo1234", "name": "Emma Clark", "language": "en" }
```

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| email | string | 필수 | 이메일 (중복 불가) |
| password | string | 필수 | 비밀번호 (bcrypt 해시 저장) |
| name | string | 필수 | 이름 |
| language | string | 선택 | `ko` 또는 `en` (기본 `ko`) |

## Response

201 Created
```json
{ "access_token": "jwt", "user": { "id": 1, "email": "emma@example.com", "name": "Emma Clark", "role": "tourist", "university_id": null, "language": "en" } }
```
`role`: `tourist` | `buddy` | `guide` | `univ_admin` | `operator` (가입 시 항상 `tourist`)

## Errors

- 409 CONFLICT: 이미 가입된 이메일
- 422 VALIDATION: 필수값 누락, 이메일 형식 오류, `language` 값 오류

## 비고

- 해커톤 단순화: 이메일 중복검사 + bcrypt 해시 저장 정도만 구현. 이메일 인증 없음.
- `role`은 요청에서 받지 않고 항상 `tourist`. `university_id`는 null. 버디·해설사·관리자는 시드 계정 사용.
