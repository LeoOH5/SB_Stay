# 리뷰 작성

- 번호: BK-08
- Method / Path: `POST /bookings/{id}/reviews`
- 역할: tourist
- 화면: T6
- 우선순위: 권장
- 처리: 목업

## Headers

| 헤더명 | 필수 | 설명 |
|---|---|---|
| Authorization | 필수 | `Bearer <JWT>` |
| Content-Type | 필수 | `application/json` |
| Accept-Language | 선택 | `ko` 또는 `en`. 응답·에러 메시지 언어 |

## Request

Path params

| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| id | integer | 필수 | 예약 ID |

Body
```json
{ "item_id": 2, "rating": 5, "text": "해설이 정말 좋았어요." }
```

## Response

200 OK
```json
{ "id": 7, "booking_item_id": 2, "rating": 5, "text": "해설이 정말 좋았어요." }
```

## Errors

- 401 UNAUTHORIZED: 토큰 없음·만료·유효하지 않음
- 403 FORBIDDEN: 본인 예약이 아님
- 404 NOT_FOUND: 예약 또는 `item_id` 항목 없음
- 409 CONFLICT: 이미 리뷰를 작성한 항목
- 422 VALIDATION: `rating` 범위(1~5) 오류 또는 `item_id` 누락

## 비고

- 권한: tourist 본인 예약의 항목만.
- 처리가 목업이므로 해커톤에서는 고정 응답 반환.
- 리뷰는 `reviews(booking_item_id, rating, text)`에 저장하는 구조.
