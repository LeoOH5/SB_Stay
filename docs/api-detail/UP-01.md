# 사진 올리기 — v3.6

- 번호: UP-01
- Method / Path: `POST /uploads` (보기: `GET /media/<yyyy>/<mm>/<file>`)
- 역할: 로그인한 사용자 (tourist · buddy · univ_admin · operator)
- 화면: B12 활동 기록 사진 · B11 식비 영수증 · T22 신고 사진 (보기: T21 앨범 · A 식비 심사 · A08 신고)
- 우선순위: 권장
- 처리: 구현

## Request

`multipart/form-data`, 필드 `file` 한 장.
- JPEG · PNG · WebP만. 종류는 확장자가 아니라 파일 앞 바이트(매직 바이트)로 확인한다.
- 10 MB(10 × 1024 × 1024 바이트)까지.

## Response

201 Created
```json
{ "url": "/media/2027/01/3f2b0c9a5d7e4b1f8a6c2d9e0b1a7c4d.jpg", "content_type": "image/jpeg", "size": 184233 }
```
- `url`은 **백엔드 주소 기준** 상대 경로다(`/api/v1` 밖). 화면은 `NEXT_PUBLIC_API_URL`에서 `/api/v1`을 뺀 주소를 앞에 붙인다(`lib/uploads.ts mediaSrc`).
- 이 `url`을 `POST /buddy/activities`의 `photos[]`, `POST /buddy/meal-claims`의 `receipt_url`, `POST /reports`의 `photo_url`에 넣는다. 그 외 값(외부 URL·파일 이름)은 422 `PHOTO_URL`.
- 저장 위치: 설정 `UPLOAD_DIR`(기본 `backend/uploads/`) 아래 `<yyyy>/<mm>/<uuid4 hex>.<ext>`.

## Errors

- 401 UNAUTHORIZED: 로그인 안 함
- 413 FILE_TOO_LARGE: 10 MB 초과
- 415 UNSUPPORTED_TYPE: JPEG · PNG · WebP가 아님 (예: 이름만 .png로 바꾼 글 파일)
- 422 EMPTY_FILE · VALIDATION(`file` 없음)

## 개인정보

사진 주소는 추측할 수 없는 무작위 이름이지만, 주소를 아는 사람은 로그인 없이 볼 수 있다. **데모용**이다.
운영 전에는 비공개 객체 저장소 + 짧은 서명 URL + 보관 기간(여행이 끝나고 정한 날이 지나면 삭제)으로 바꾼다. 바꿀 곳은 `app/services/storage.py` 하나.
