## 데모 순서
1. Emma로 로그인 → 홈 "AI로 여행 설계하기" → 추천 일정(숙박 + 버디 + 무료 코스) → 모두 장바구니에 담기 → 여행자 정보 → 예약 신청
2. 대학 담당자로 로그인 → 대시보드에서 숙박 승인
3. 지우로 로그인 → 요청함에서 동행 요청 수락(정산율 75% 고정) → 식비 청구·활동 기록 → 내 활동에서 등급 카드 확인
4. 운영자로 로그인 → 식비 청구 승인, 신고 처리, 정산 확인
5. Emma로 다시 로그인 → 내 여행에서 확정·식사비·앨범 확인, 후기 남기기
